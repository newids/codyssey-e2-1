# MVP Building — 실습 교육용 시스템 구축 규칙

## 제품 정의

전 국민 대상 AI 모의사기 훈련 서비스의 실습 교육용 MVP. 핵심 루프는 **사전 교육(대응 방안 최소 학습) → 진단 → 집중 노출 훈련 → 재측정**이다. 지식 전달이 아니라 "사기 순간에 작동하는 행동"을 만드는 것이 목표 — 화면·문안 설계 시 항상 이 기준으로 판단한다.

## 기술 스택 (고정)

- React 18 + Vite 5, 의존성 추가는 명확한 사유 없이 금지 (현재 런타임 의존성은 react/react-dom뿐 — 유지)
- **정적 우선**: 기본 원칙은 런타임 LLM/서버 호출 없음 — 적응형 해설·교육 문안은 데이터셋의 `clues`·메타데이터를 클라이언트에서 프로파일별로 렌더링. **예외(2026-08-20, 전략 v3.0)**: AI 가이드 해설 1경로에 한해 런타임 LLM 호출 허용 — 단 규칙 기반 폴백 상시 유지, 빌드 산출물에 API 키 미포함, 호출 상한(세션·일·월) 적용. 그 외 경로는 정적 원칙 유지
- 상태: localStorage (프로파일, 진행도, 측정 기록)
- 테스트: vitest (`npm test`), 로직은 `src/lib/`에 순수 함수로 분리해 테스트
- 배포 대상: GitHub Pages `https://newids.github.io/codyssey-e2-1/app/` — vite.config.js의 base 경로를 깨뜨리지 않는다

## 예산·품질 기준

- JS 번들 80KB gzip 이내 (`npm run build` 출력으로 확인)
- 모바일 우선(375px 기준), 시니어 프로파일은 큰글씨·고대비·단계별 문장
- LaTeX/MathJax 금지, 모든 문안 한국어
- 종료 조건: `npm test` 전체 통과 + `npm run build` 성공. 둘 중 하나라도 실패한 채 완료 선언 금지

## 데이터 원칙

- 데이터셋: `mvp/data/scam_dataset_v0.1.json` (사기 30 + 정상 10). 문항 추가 시 수법 패턴만 추출해 전면 재작성 — 실사례 원문 전재 금지
- 전화번호는 0000 계열, URL은 `*.example`만 사용. 실존 기관명 사칭 문안은 "OO은행" 식 가상 표기
- 정상 문항을 반드시 섞어 오탐(정상을 사기로 판정) 훈련을 유지한다

## 파일 구성 관례

- 화면 컴포넌트: `src/components/{Name}.jsx` (PascalCase)
- 로직·데이터 변환: `src/lib/{name}.js` — 컴포넌트에 비즈니스 로직을 넣지 않는다
- 스타일: `src/styles/global.css`의 CSS 커스텀 프로퍼티 토큰을 재사용 — 새 색·크기 하드코딩 금지

## 작업 절차

1. 기존 코드(`App.jsx`의 화면 흐름, `src/lib/`)를 읽고 현재 루프를 파악한다
2. 전략 문서의 요구를 화면·로직 단위 작업 목록으로 분해한다
3. 로직부터: `src/lib/`에 순수 함수 + vitest 테스트 → 통과 확인 후 컴포넌트 연결
4. `npm test` + `npm run build` 통과 확인, 번들 크기 기록
5. `docs/idea-1/_workspace/07_mvp_notes.md`에 변경 요약 작성 (전략 항목 ↔ 구현 매핑, 테스트·빌드·번들 결과, 잔여 항목)
