01

콘텐츠는 있지만 진단이 없다

모바일 금융 실습·사기 시뮬레이션 등 체험형 금융교육은 이미 확산 중이다. 그러나 역량별 학습이 여러 서비스에 흩어져 있어, 무엇이 부족하고 어떤 학습이 필요한지 사용자가 스스로 판단할 수 없다.

02

같은 연령대라도 부족한 역량이 다르다

모바일뱅킹 조작이 서툰 사람, 신용·대출 개념이 약한 사람, 지식은 있어도 실제 사기 상황에서 위험한 선택을 하는 사람이 공존한다. 획일적 교육으로는 대응할 수 없다.

03

필요한 것은 '진단–연결 구조'

또 하나의 콘텐츠가 아니다. 실제 금융과업 수행 과정에서 현재 역량을 진단하고, 필요한 교육·실습을 개인별로 연결하는 구조가 필요하다.

사람 강사가 모든 사용자를 1:1로 관찰·지도할 수는 없다 — 이 개인화를 대규모로 구현하는 수단이 AI다.

AI 기술 적용 방안04 / 10

3대 핵심 기능, 단계적 고도화 경로

핵심 기능적용 기술기술 설명
금융역량 진단 Rule-based Scoring → ML (분류·회귀 모델) 사용자의 행동 데이터를 기준과 가중치에 따라 점수화하고, 이후 축적된 데이터를 학습한 ML 모델로 고도화한다.
AI 가이드형 실습 Instruction LLM + Context Prompting + RAG LLM으로 자연어 안내·피드백을 생성하고, 프롬프트에 사용자 수준 · 현재 미션 단계 · 오류 이력 · 힌트 단계를 전달해 응답 방식을 조정한다. RAG로 공식 금융자료를 답변 근거로 활용한다.
개인별 학습경로 추천 Rule-based 추천 → Learning-to-Rank 사용자 프로필과 사전 정의된 규칙으로 추천하고, 향후 데이터가 쌓이면 사용자별 학습효과를 반영해 추천을 정교화할 수 있다.
기술 선택 이유

초기에는 데이터가 없으므로 규칙·가중치 기반으로 즉시 동작하는 구조를 택했다. 사용 데이터가 축적되면 동일한 기능을 ML · Learning-to-Rank로 교체해 정교화한다.

왜 AI여야 하는가

사람 강사가 대규모 사용자를 1:1로 관찰·지도할 수 없다. 개인별 진단 → 맞춤 안내 → 다음 학습 연결을 동시에, 대규모로 수행하는 수단은 AI뿐이다.

핵심 제안10 / 10

콘텐츠를 하나 더 만드는 서비스가 아니다

결론

금융 코디세이는 새로운 금융교육 콘텐츠를 하나 더 만드는 서비스가 아니다. 사용자의 실제 금융 미션 수행을 통해 '지금 무엇을 어려워하는지'를 파악하고, AI가 필요한 도움과 다음 금융과업을 연결함으로써 흩어진 금융교육을 개인별 하나의 학습 여정으로 만드는 플랫폼이다.

기능 01

미션 기반 역량 진단

행동 데이터를 기준과 가중치에 따라 점수화해 영역별 취약도를 파악한다.

기능 02

AI 가이드형 실습

사용자 수준·미션 단계·오류 이력에 맞춘 안내를 생성하고, 공식 금융자료를 근거로 제시한다.

기능 03

개인별 학습경로 추천

역량 프로필을 기준으로 기초금융·금융안전·생활금융 중 다음 학습을 연결한다.
