# codyssey-e2-1 — 텀 프로젝트(아이디어톤) 리포지토리

> 코디세이 AI 올인원 **미션 e2-1** 수행용 리포지토리.
> 과제: 7대 도메인 중 하나를 골라 팀 단위로 AI 서비스를 기획 — 산출물은 **서비스 기획서(A4 2쪽) + 발표자료(10쪽)**, 범위는 기획·아키텍처 설계까지 (요구사항 전문: `docs/Mission-e2-1.md`)

- 도메인: **AI Fintech** · 팀 5인
- 아이디어별 산출물은 `docs/idea-N/`에 정리한다. 현재 제출 후보로 발전 중인 아이디어는 **idea-1(금융 코디세이)** 1건이다.

## 제출 예정 아이디어 — idea-1: 금융 코디세이(가칭)

**AI 모의사기 훈련 서비스. 한 문장 정의:** 당신이 어떤 미끼에 약한지 AI가 찾아내고, 그 미끼만 골라 예고 없이 반복해서 던지는 모의사기 훈련 서비스.

문제는 지식 부족이 아니라 **아는 것이 사기 순간에 작동하지 않는 것**(지식-행동 전이 실패)이다. 해법은 `진단 → 집중 노출 → 재측정 → 프로필 갱신`의 반복 훈련 루프이며, 시스템은 **결정론 코어 C1–C6**(상태기계·정답 판정·스케줄러·프로필 저장소·안전 가드·감사 로그)와 **AI 레이어 A1–A5**(프로파일링·적응 라우터·시나리오 생성·RAG 판별·쉬운말/음성)로 분리된다. 이 경계선이 금융위 AI 활용 7대 원칙(재현·감사 가능성)에 대한 답이다.

## 개발 (idea-1 MVP)

```bash
# 판별 퀴즈 웹앱
cd mvp/web && npm install
npm run dev            # 로컬 개발 서버
npm test               # vitest 단위 테스트 10개
npm run build          # 정적 빌드 (JS 56KB gzip, 예산 80KB)

# 적응형 프롬프트 비교 (프로파일별 출력 차이 검증)
export ANTHROPIC_API_KEY=<키>
cd mvp/prototype && python3 run_compare.py --item S01 --save
```

`run_compare.py`는 동일한 사기 문자를 senior/youth 두 프로파일에 넣어 출력을 비교한다. 결과가 `golden/S01_*.md`의 구조·톤(단계별·큰글씨 vs 요점 카드)에 수렴하는지가 합격 기준이다.

## 작업 규칙 (요약)

- 모든 산출물은 **한국어**. 톤은 문제해결 중심·담백한 지적 호기심, 서사 과잉 지양.
- 통계 인용 시 **기준 연도·출처 병기** (예: "경찰청 국수본, 2025년 1분기"). 수치는 `PROJECT_BRIEF.md`에서 인용하고 임의 재생성 금지.
- 교육 자료·웹 산출물에 **LaTeX/MathJax 금지** (모바일 가독성).
- 사기 문항의 전화번호·URL은 전부 가상 표기(`0000` 계열, `*.example`) — 실서비스 반영 전 검수 필수.
- 피드백 반영·기획서/덱 개정·심사 검증·제출 준비는 `idea-development` 스킬로 처리한다. 전체 규칙과 백로그는 `CLAUDE.md`.
