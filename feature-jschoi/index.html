프로토타입 범위 — 3대 학습 영역 가운데 금융안전 영역의 사기문자 판별 실습 일부만 구현한 정적 프로토타입이다. 기초금융·생활금융 영역과 학습경로 추천은 설계 단계이며 구현되지 않았다.

01

문제 정의

기존 금융교육 한계: 콘텐츠는 있지만 진단이 없음 모바일 금융 실습, 사기 시뮬레이션 등 체험형 금융교육은 이미 존재한다. 그러나 역량별 학습이 여러 서비스에 흩어져 있어, 사용자는 자신에게 무엇이 부족하고 어떤 학습이 필요한지 스스로 판단할 수 없다.
같은 연령대라도 부족한 역량이 다름 모바일뱅킹 조작이 서툰 사람, 신용·대출 개념이 약한 사람, 지식은 있어도 실제 사기 상황에서 위험한 선택을 하는 사람이 공존한다. 획일적 교육으로는 대응할 수 없다.
필요한 것은 '또 하나의 콘텐츠'가 아니라 '진단-연결 구조' 실제 금융과업 수행 과정에서 현재 역량을 진단하고, 필요한 교육·실습을 개인별로 연결하는 구조가 필요하다.
02

타겟 사용자

우선 순위교육 니즈 · 역량 취약도대표 학습
1. 고령층(60대+)디지털정보화 71.4%, 최저(NIA, 2024)모바일 송금, 금융문서 이해, 기관사칭 대응
2. 청년(20-30대)사회생활·자산형성 시작 / 기관사칭 피해자 52%가 30대 이하(2025)신용·대출 이해, 청년 지원제도 탐색
3. 중장년(50대)자산관리·재무 재설계 / 사기 피해자 중 50대 이상 53%(2025)투자·대출 판단, 퇴직연금, 금융사기 대응
4. 청소년(10대)금융 기본습관 형성예산관리, 온라인 거래 위험 판단

우선 순위는 향후 발전 방향의 1~3단계와 같은 순서를 따른다. 인용 통계의 기관·기준 시점은 부록 B에 정리했다.

03

서비스 개요

금융 코디세이는 금융 미션 수행 데이터를 바탕으로 금융역량을 진단하고, AI 가이드와 개인별 학습경로를 제공하는 맞춤형 금융학습 플랫폼이다.

3대 학습 영역

학습 영역다루는 내용
기초금융계좌이체, 자동이체, 신용점수, 대출금리, 금융문서 이해
금융안전보이스피싱·스미싱·악성앱·기관사칭·투자사기 대응
생활금융지원제도 탐색, 청년·퇴직·연금 정보 이해, 금융조건 비교

미션 수행 결과를 금융역량 프로필로 연결해 사용자의 취약 영역에 맞는 학습을 제공한다.

차별점

차별점은 콘텐츠가 아니라 구조다. 체험형 금융교육 콘텐츠는 이미 존재하지만 역량별로 흩어져 있어, 사용자는 자신에게 무엇이 부족한지 스스로 판단할 수 없다. 금융 코디세이는 콘텐츠를 하나 더 만드는 대신, 실제 금융과업 수행 과정에서 역량을 진단하고 필요한 학습을 개인별로 연결하는 구조를 만든다.

04

AI 기술 적용

핵심 기능적용 기술기술 설명
금융역량 진단Rule-based Scoring → ML(분류/회귀 모델)사용자의 행동 데이터를 기준과 가중치에 따라 점수화한다. 축적된 데이터를 학습한 ML 모델로 고도화한다
AI 가이드형 실습Instruction LLM + Context Prompting + RAGLLM으로 자연어 안내·피드백을 생성한다. 프롬프트에 사용자 수준·현재 미션 단계 등 조건을 전달해 응답 방식을 조정한다. RAG를 통해 공식 금융자료를 답변 근거로 활용한다
개인별 학습경로 추천Rule-based 추천 → Learning-to-Rank사용자 프로필과 사전 정의된 규칙으로 추천한다. 향후 데이터가 쌓이면 사용자별 학습효과를 반영해 추천을 정교화한다

세 기능은 모두 규칙 기반으로 지금 동작하고, 데이터가 쌓이면 학습 기반으로 고도화되는 2단 구조다 — 현재 구현 가능한 경로와 향후 고도화 경로를 함께 밝힌다.

05

시스템 구성

사용자 │ 미션 수행 요청 ▼ API Gateway — 인증 / 인가 │ ▼ API server ──── 미션 컨텍스트 ────▶ AI (LLM) │ ◀──── 가이드 / 피드백 / 근거 ────┘ │ │ 정제 텍스트 임베딩 요청 │ 프로필 조회 · 수행기록 저장 │ 임베딩 벡터 근거 검색 ▼ ▼ Database ◀──────────────────── Pipeline ▲ │ 원문 수집 금융 공공정보 · 제도 · 혜택정보
구분흐름
요청 흐름사용자의 미션 수행 요청이 API Gateway의 인증·인가를 거쳐 API server로 전달된다
AI 호출API server가 미션 컨텍스트를 AI(LLM) 에 전달하고, 가이드·피드백·근거를 받아 사용자에게 제공한다
데이터API server는 Database에서 프로필을 조회하고 수행기록을 저장한다. AI는 임베딩 벡터 근거 검색으로 답변 근거를 가져온다
외부 수집Pipeline이 금융 공공정보·제도·혜택정보 원문을 수집해 정제 텍스트를 임베딩하고 Database에 적재한다
