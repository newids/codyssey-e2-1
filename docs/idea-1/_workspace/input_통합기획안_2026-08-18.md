# 통합 기획안 입력 (사용자 제공 확정 콘텐츠, 2026-08-18)

> 이 문서는 사용자가 발표자료(10p) 작성을 위해 직접 제공한 확정 콘텐츠다.
> 발표자료는 이 서사를 기준으로 작성한다. (기존 전략 v1.2 "AI 모의사기 훈련" 단독 서사가 아니라,
> "미션 기반 진단–연결 개인 맞춤형 금융학습 플랫폼"으로 통합된 팀 최종 서사)

- 도메인: AI Fintech
- 서비스 비전: 사용자의 실제 금융 미션 수행을 기반으로 금융역량을 파악하고, AI가 기초 금융·금융안전·생활금융 중 필요한 다음 학습을 연결하는 개인 맞춤형 금융학습 플랫폼

## 1. 문제 정의

1. **콘텐츠는 있지만 진단이 없다** — 모바일 금융 실습, 사기 시뮬레이션 등 체험형 금융교육은 이미 확산 중이다. 그러나 역량별 학습이 여러 서비스에 흩어져 있어, 사용자는 자신에게 무엇이 부족하고 어떤 학습이 필요한지 스스로 판단할 수 없다.
2. **같은 연령대라도 부족한 역량이 다르다** — 모바일뱅킹 조작이 서툰 사람, 신용·대출 개념이 약한 사람, 지식은 있어도 실제 사기 상황에서 위험한 선택을 하는 사람이 공존한다. 획일적 교육으로는 대응할 수 없다.
   - 역량 격차: 성인 금융이해력 65.7점(하락 추세) · 취약계층 디지털 접근 96.5% vs 활용역량 65.6%
   - 피해 규모: 보이스피싱 피해액 7,766억 원(2025.1~7월)
3. **필요한 것은 '또 하나의 콘텐츠'가 아니라 '진단–연결 구조'다** — 실제 금융과업 수행 과정에서 현재 역량을 진단하고, 필요한 교육·실습을 개인별로 연결하는 구조가 필요하다. 사람 강사가 모든 사용자를 1:1로 관찰·지도할 수 없으므로, 이 개인화를 대규모로 구현하는 수단이 AI다.

## 2. 타겟 사용자

금융 코디세이는 특정 연령층이 아니라 생애주기별 금융과업을 가진 전 국민이 대상이나, 다음과 같이 우선순위를 두고 타겟 사용자를 설정하고 추진한다.

| 대상 (우선순위 순) | 교육 니즈 · 역량 취약도 | 대표 학습 |
|---|---|---|
| 고령층(60대+) | 디지털정보화 71.4%, 최저(NIA 2024) | 모바일 송금, 금융문서 이해, 기관사칭 대응 |
| 청년(20–30대) | 사회생활·자산형성 시작. 기관사칭 피해자 52%가 30대 이하(2025) | 신용·대출 이해, 청년 지원제도 탐색 |
| 중장년(50대) | 자산관리·재무 재설계. 사기 피해자 중 50대 이상 53%(2025 1분기, 2023년 32%) | 투자·대출 판단, 퇴직연금, 금융사기 대응 |
| 청소년(10대) | 금융 기본습관 형성 | 예산관리, 온라인 거래 위험 판단 |

연령은 초기 추천의 참고정보로만 활용하고, 실제 학습경로는 **미션 수행 결과·반복 오류·AI 도움 필요 수준** 등 행동 데이터를 중심으로 개인화한다.

## 3. 서비스 개요

금융 코디세이는 금융 미션 수행 데이터를 바탕으로 금융역량을 진단하고, AI 가이드와 개인별 학습경로를 제공하는 맞춤형 금융학습 플랫폼이다.

- **기초금융**: 계좌이체, 신용·대출, 금융문서 이해
- **금융안전**: 보이스피싱·스미싱·기관사칭·투자사기 대응
- **생활금융**: 지원제도 탐색, 청년·퇴직·연금 정보 이해, 금융조건 비교

기존 금융교육과 달리 개별 콘텐츠 제공에 그치지 않고, 미션 수행 결과를 금융역량 프로필로 연결해 사용자의 취약 영역에 맞는 학습을 제공한다.

## 4. AI 기술 적용 방안

| 핵심 기능 | 적용 기술 | 기술 설명 |
|---|---|---|
| 금융역량 진단 | Weighted Rule-based Scoring → ML(분류/회귀 모델) | 사용자의 행동 데이터를 기준과 가중치에 따라 점수화하고, 이후 축적된 데이터를 학습한 ML 모델로 고도화한다. |
| AI 가이드형 실습 | Instruction LLM + Context Prompting + RAG(Embedding 기반 검색) | LLM으로 자연어 안내·피드백을 생성하고, 프롬프트에 사용자 수준·현재 미션 단계·오류 이력·힌트 단계 등의 조건을 전달해 응답 방식을 조정한다. RAG를 통해 공식 금융자료를 답변 근거로 활용한다. |
| 개인별 학습경로 추천 | Profile-based Rule Recommendation → Learning-to-Rank | 사용자 프로필과 사전 정의된 규칙으로 추천하고, 향후 데이터가 쌓이면 사용자별 학습효과를 반영해 추천을 정교화할 수 있다. |

## 5. 예상 시스템 구성

- **요청 흐름**: 사용자 앱 → API G/W → API 서버가 미션 요청 → AI 모델이 학습 제공
- **AI 적용**: Instruction LLM + Context Prompting + RAG로 실시간 안내 및 피드백 생성
- **AI 미적용**: 정답 판정, 학습 결과 등은 API 서버에서 처리
- **외부 데이터**: 파이프라인이 프록시를 경유해 조회 요청만 송신, AI 모델을 활용해 검증 및 절제 후 DB에 적재

(다이어그램은 발표자료에서 시각화)

## 6. 비즈니스 모델

공공/금융기관 및 금융/통신사가 서비스 사용료를 지불하고 사용자인 금융 취약계층은 무료로 이용하는 구조.
고객은 포용 금융 및 ESG 경영을 실천해야 하는 Needs가 있어 지불의사가 있으며, 금융 취약계층은 무료로 금융 피해를 최소화할 수 있어 사용에 대한 Needs가 존재.

| 수익 구조 | 고객 유형 | 가격 책정 방식 |
|---|---|---|
| B2B2C | 은행, 증권사, 보험사, 통신사 | 1) API 사용량 기반 과금(Pay as you go) 2) 라이선스 구독(월/연 단위) |
| B2B2G | 금융/소비자 보호 규제 기관, 광역·기초 지자체, 치안/범죄 예방 기관 | (동일 과금 체계 적용) |

## 7. 기대 효과

- **연령대별 금융 이해력 향상**
  - 금융 사기 인지율 기존 대비 75% 이상 향상
  - 금융 사기 대응을 위한 안전 행동 실천율 20~30% 개선
- **금융 사기 피해 감소**
  - 개인 대상 연간 금융 사기 피해액 약 1,380억 원 감소
  - 금융 사고 발생에 대한 민원 처리 및 행정 비용 감소
- **포용 금융 및 ESG 경영 실현**
  - 금융 취약계층의 디지털 채널 활용 금융 서비스 이용 안전성 증대
  - 금융 예방 교육 이수시간 등 금융사에 정량화 가능한 사회공헌 지표 제공

## 9. 팀 역할 분담

팀 역할은 향후 개발 직무가 아니라, 이번 기획서를 작성하는 과정에서 각 팀원이 담당한 조사·설계·정리 영역과 기여 내용을 기준으로 작성한다.

| 담당 영역 | 기획서 작성 과정에서의 기여 내용 |
|---|---|
| 기획 총괄 | 아이디어 방향 설정, 문제 정의, 서비스 핵심 콘셉트 및 전체 기획서 구성·통합 |
| 시장·사례 조사 | 기존 금융교육·AI 금융서비스 및 유사 서비스 조사, 기존 서비스 대비 차별점 도출 |
| AI 기술 조사 | LLM, RAG, 행동 데이터 분석, 개인화 추천 등 적용 가능한 AI 기술 조사 및 적용 방안 구체화 |
| 금융·데이터 조사 | 금융이해력, 디지털 역량, 금융사기 피해 등 관련 통계·정책·공공데이터 조사 |
| 서비스 설계·발표 | 타겟 사용자, 학습 흐름, 시스템 구성, 기대 효과·사업화 방향 정리 및 발표자료 구성 |

## 핵심 제안 (클로징 메시지)

금융 코디세이는 새로운 금융교육 콘텐츠를 하나 더 만드는 서비스가 아니다. 사용자의 실제 금융 미션 수행을 통해 '지금 무엇을 어려워하는지'를 파악하고, AI가 필요한 도움과 다음 금융과업을 연결함으로써 흩어진 금융교육을 개인별 하나의 학습 여정으로 만드는 플랫폼이다.
