# 린 캔버스 — 금융 코디세이

> **금융 코디세이 — 금융역량 진단-연결 AI 플랫폼** · 문서 버전 2.0 · 2026-08-20 · 팀 포디세이(Fodyssey)
> 이 캔버스는 **사업계획서의 압축본**이다. 캔버스에만 있는 주장·수치는 없으며, 문자열이 어긋나면 사업계획서가 기준이다.

---

## 1. 문제

| 내용 |
|---|
| ① 콘텐츠는 있으나 개인의 현재 역량을 진단하는 수단이 없다 |
| ② 연령대는 역량의 대리 지표가 되지 못한다 |
| ③ 공공·금융기관은 교육 참여 인원은 세지만 역량 변화는 측정하지 못한다 |

**근거** — 취약계층 디지털정보화에서 접근 96.5% · 활용 80.0%는 이미 높은데 역량만 65.6%로 낮다(NIA, 2024 — 부록 B [8]).

## 2. 고객군

| 구분 | 내용 |
|---|---|
| **학습자(사용자)** | **1순위 고령층(60대+)** — 프로토타입·검증·첫 고객 100%. 2~4순위(청년·중장년·청소년)는 로드맵 2·3단계 |
| **구매자** | **1순위 지방자치단체·공공기관** / **2순위 금융회사**(은행·증권사·보험사·통신사) |

**근거** — 사용자와 구매자가 다르다. 학습자는 고령층이고 값을 내는 쪽은 금융회사·공공기관이다. 순위는 진입 순서이며 중요도 서열이 아니다.

## 3. 고유 가치 제안

| 내용 |
|---|
| **우리가 파는 것은 콘텐츠가 아니라 개인의 금융역량 진단이다.** |
| 콘텐츠를 하나 더 만드는 것이 아니라, 흩어진 학습을 개인의 진단 결과에 연결하는 구조를 만든다. |

**근거** — 사용자가 금융과업을 수행하는 행동 데이터로 금융역량을 진단하고, 그 진단 결과를 API로 금융회사·공공기관에 공급한다. 학습은 출력물이지 상품이 아니다.

## 4. 솔루션

| 구분 | 내용 |
|---|---|
| **AI 3기능** | 금융역량 진단 · AI 가이드형 실습 · 개인별 학습경로 추천 (전부 「Rule → ML/LLM」 2단 구조) |
| **진단 프레임 4단** | 금융 과업(미션) → 관측 행동 신호 → 규칙 채점 → 영역 점수(0~100) |
| **결과 형태** | 기초금융·금융안전·생활금융 **3축 프로필 — 합산하지 않는다** |

**근거** — 연결의 입력은 총점이 아니라 「어느 영역이 낮은가」이므로, 총점은 취약 영역을 평균으로 가려 버린다.

## 5. 채널

| 구분 | 내용 |
|---|---|
| **B2B2G** | 지방자치단체·공공기관의 고령층 금융교육 사업(첫 진입 경로) |
| **B2B2C** | 금융회사 자사 앱 내 진단 위젯 → 진단 API 계약 |
| **없는 것** | 개인 사용자에게 직접 과금하는 채널 |

**근거** — 공공 사업은 구매 결정 단위가 작고, 효과 측정 부재라는 페인이 명확하며, 집단 리포트가 이미 산출된다. 금융회사는 공공 레퍼런스 확보가 선행 조건이다.

## 6. 수익원

| 구분 | 과금 단위 |
|---|---|
| **B2B2C** | 진단 API 호출 과금 |
| **B2B2G** | 라이선스 구독(월·연) + 집단 리포트 |
| **가격** | **단가 미확인.** 가격 결정 변수는 활성 사용자 수 · 진단 호출 빈도 · 리포트 발행 주기 |

**근거** — 유사 B2B API 라이선스 단가 사례를 확보하지 못했으므로 금액을 쓰지 않는다. 금융상품 판매·중개·자문 수익은 없다.

## 7. 비용 구조

| 항목 |
|---|
| 콘텐츠·시나리오 제작(사람 검수 포함) |
| LLM 추론 비용 |
| 공공데이터 수집·정제 파이프라인 |
| 개인정보 보호 운영(가명처리·집계·재식별 방지) |

**근거** — 금액 없이 항목만 적는다. 실제 단위 비용은 첫 도입 사례에서 호출량이 관측된 뒤에 산출된다.

## 8. 핵심 지표

| 지표 | 상태 |
|---|---|
| **금융안전 취약도 개선폭** | 현재 코드로 산출 가능 |
| **사기 판별 정확도 / 오탐률** | 현재 코드로 산출 가능 |
| **학습경로 추천 수용률** | 설계 완료 · 구현 필요 |

**근거** — 효과를 숫자로 약속하는 대신 측정 방법을 제출한다. 사전 진단 → 실습 → 사후 재진단의 3측정으로 수집한 값이 기대효과 수치의 최초 근거가 된다.

## 9. 경쟁 우위

| 내용 |
|---|
| ① 진단이 있고, 개인의 취약 영역 단위로 개인화되며, 그 결과가 다음 학습을 정하고, 지키는 대상이 사람의 판단력인 조합은 조사 범위 안에서 **조직 구성원을 대상으로만** 성립했다 |
| ② 본문의 모든 통계에 출처 항목 번호가 붙는다(부록 B 22건 전수 검증) |
| ③ 작동하는 정적 프로토타입이 공개 배포돼 있다 |
| ④ 진단 산식이 문서가 아니라 코드와 단위 테스트로 결속돼 있다 |

**근거** — 경쟁 15종을 4축(진단 유무 · 개인화 단위 · 진단–학습 연결 · 무엇을 지키는가)으로 비교한 결과다(확인 2026-08-17). 「확인되지 않았다」는 부재의 증명이 아니다.
