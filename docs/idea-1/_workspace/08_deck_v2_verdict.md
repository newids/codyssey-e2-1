## ② 차단 요건 (BLOCK) — 제출 전 반드시 수정

### B-1. 65.6%를 "활용역량"으로 표기 — NIA 지표 정의 오기 (위치: 슬라이드 02 스탯 밴드)

**현재 문안**

```
96.5% → 65.6%   취약계층 디지털 접근 대비 활용역량
                NIA 디지털정보격차실태조사, 2024
```

**사실관계 대조**

| 출처 | 표기 |
|---|---|
| `PROJECT_BRIEF.md` L40 | "취약계층 '역량' 부문 **65.6%**로 **접근(96.5%)·활용(80.0%)** 대비 최저" |
| 정본 `Term-Project_기획안_v1.md` L10 | "접근 96.5%·**활용 80.0%**인데 **역량만 65.6%**" |
| 입력 문서 §1 | "디지털 접근 96.5% vs **활용역량** 65.6%" ← **오기 발원지** |
| 07 덱 02/10 | "디지털 접근 대비 **활용역량**" ← 입력의 오기를 그대로 계승 |

NIA 디지털정보격차 실태조사의 하위 지표는 **접근 / 역량 / 활용** 3종이며, 취약계층 **활용은 80.0%**, **역량이 65.6%**다. 덱의 "활용역량"은 서로 다른 두 지표를 한 단어로 붙여 놓아, 실제 활용 지표(80.0%)를 65.6%로 잘못 제시하는 결과가 된다. 3차 판정 통과본(정본)은 이 세 값을 정확히 구분해 적고 있으므로, 이번 덱은 **승인된 표기에서의 회귀**다.

**수정 지시 (택1, deck-producer)**

- (권장) `96.5% → 65.6%` / 라벨 `취약계층 디지털 **접근** 대비 **역량**` / 각주 `활용 80.0% · NIA 디지털정보격차 실태조사, 2024`
- (최소) 라벨의 "활용역량"을 **"역량"** 한 단어로 교체.

> **심사위원 예상 질문:** "NIA 조사에서 취약계층 활용 지표는 80%대로 알고 있는데, 65.6%는 어느 항목입니까? 지표를 잘못 보신 것 아닙니까?"

### B-2. 53%를 "사기 피해자 중" 비중으로 표기 — 피해액/피해자 관점 혼동 (위치: 슬라이드 03 3순위 행)

**현재 문안**

```
자산관리·재무 재설계. 사기 피해자 중 50대 이상 53%(2023년 32%)   [2025년 1분기]
```

**사실관계 대조**

| 출처 | 표기 |
|---|---|
| `PROJECT_BRIEF.md` L52 | "50대 이상 **피해 비중**: 2023년 32% → 2024년 47% → 2025년 1분기 53% (경찰청 국수본)" |
| `CLAUDE.md` 백로그 주의문 | "브리프 '50대 이상 53%'는 국수본 발표(**피해액 관점**) 기준 — 경찰청 **연령별 건수** 데이터(20대 이하 24.7% ≈ 60대 24.8%, 2025)와 **별개 지표로 병기할 것**" |
| 정본 v1 L20 | "50대 이상 **53%**(2025 1분기, 2023년 32%)" — 관점 단정 회피 |
| 07 덱 03/10 | "**사기 피해자 중** 50대 이상 53%" ← **피해자 수 관점으로 단정** |

프로젝트가 자체 백로그에 "이건 피해액 기준이니 건수와 병기하라"고 명시해 둔 항목을, 덱이 **피해자 수 기준으로 바꿔 서술**했다. 게다가 같은 슬라이드 바로 위 행에는 "기관사칭 피해자의 52%가 30대 이하"가 있어, 두 수치의 기준(피해액 vs 피해자 수, 기관사칭형 vs 전체)이 다름에도 **동일한 '피해자 비중'처럼 나란히 배치**돼 있다. 심사위원 눈에는 52% + 53%가 한 표에서 충돌하는 것으로 보인다.

**수정 지시 (deck-producer)**

1. "사기 피해자 중" → **"보이스피싱 피해액 중"** 또는 브리프 표현대로 **"피해 비중(피해액 기준)"** 으로 교체.
2. 2순위 행의 52%에는 **"기관사칭형 피해자 수 기준"** 을 명시해 지표를 분리한다.
3. (권장) `CLAUDE.md` 지시대로 건수 지표 1건 병기 — "연령별 **건수** 기준으로는 20대 이하 24.7% ≈ 60대 24.8%(경찰청, 2025)" — 그래야 "50대가 최다"라는 오해 반박을 선제 방어한다.

> **심사위원 예상 질문:** "50대 이상이 피해자의 53%라면, 아까 청년이 기관사칭 피해자의 52%라는 건 어떻게 동시에 성립합니까? 두 숫자의 분모가 각각 뭡니까?"

## ④ 수정 권고 (6건 — 수상 가능성 저하)

### W-1. 통계 2건에 출처 기관 미병기 — `CLAUDE.md` 명시 규칙 위반 (슬라이드 03)

`CLAUDE.md` 작업 규칙: "통계 인용 시 **반드시 기준 연도·출처 병기**(예: '경찰청 국수본, 2025년 1분기')". 슬라이드 03의 52%·53%는 **연도만 있고 기관이 없다.** 같은 덱의 슬라이드 02는 세 수치 모두 기관을 병기하고 있어 **문서 내부에서도 표기 기준이 갈린다.**
→ 수정: 52% 행에 `경찰청, 2025`(브리프 §6 뉴데일리 보도 기준 — 원자료 표기는 확인 후 확정), 53% 행에 `경찰청 국수본, 2025년 1분기`. 담당: deck-producer.

> **예상 질문:** "이 52%, 53%는 어디 자료입니까? 옆 슬라이드는 출처를 다 달았는데 여기만 없네요."

### W-2. "주제 선택 이유"가 명시적으로 없다 — Mission 필수 항목의 하위 요건 (슬라이드 02)

`Mission-e2-1.md` §4-3 표: **문제 정의 = 해결하고자 하는 문제와 그 배경 + 주제 선택 이유**. 덱 02는 문제·배경·AI 필연성을 다루지만, **"왜 AI Fintech에서 이 주제인가"** 를 한 문장으로 선언하는 자리가 없다. 과제 목표 6항목 중 "AI가 해결할 수 있는 문제를 정의하고 **그 배경을 설명**"과도 직결.
→ 수정: 02 하단 클로징 문장 앞 또는 표지 리드 하단에 1행 추가 (예: "금융은 실수의 대가가 즉시 금전 손실로 확정되는 도메인이며, 학습 효과를 **행동 데이터로 측정할 수 있는** 몇 안 되는 영역이다 — 그래서 AI Fintech에서 이 주제를 골랐다"). 담당: deck-producer.

### W-3. '내부 추정 1,380억 원'의 산출 근거 미제시 (슬라이드 08)

라벨('내부 추정')을 붙인 것은 적절한 방어이나, **산정 방식이 한 줄도 없다.** 같은 덱 02가 제시한 7,766억(2025.1~7월, 연환산 약 1.33조) 대비 약 10% 수준이라 "왜 10%인가"가 즉시 질문된다. 75%·20~30%도 동일(비교 기준·측정 방법 미상).
→ 수정: 하단 note에 산정식 1줄 추가 (예: "연환산 피해액 × 도입 커버리지 가정 × 인지율 개선 효과 — 상세 산정표는 부록"). 부록이 없다면 "PoC 사전·사후 비교로 검증 예정"만 남기고 절대액을 **범위 표기**로 완화. 담당: strategy-planner → deck-producer.

> **예상 질문:** "1,380억은 어떻게 나온 숫자입니까? 커버리지 몇 %, 효과 몇 %를 가정했습니까?"

### W-4. 웹폰트 미로딩 — 제출 PDF의 조판이 기계마다 달라진다

`--font-sans: "Pretendard Variable", Pretendard, ...` 를 쓰면서 **웹폰트 링크(@font-face / CDN)가 없다.** Pretendard 미설치 환경에서는 Apple SD Gothic Neo / Noto Sans KR로 폴백되며 자간·줄바꿈이 달라진다. 이 덱은 `.slide { height: 720px; overflow: hidden }` 고정이므로, 폴백으로 1~2행이 늘어나면 **경고 없이 잘려 나간다**(이전 정본 덱은 인쇄 시 `overflow: visible`이라 넘침이 눈에 보였다 — 이 덱은 **조용한 잘림**이다).
→ 수정 (택1): (a) Pretendard CDN `<link>` 추가, (b) `@media print`에 `.slide { overflow: visible }` 추가해 넘침을 가시화, (c) **최소한** 실제 제출 기기에서 PDF를 내보내 10쪽·잘림 0을 육안 실측. 담당: deck-producer.

### W-5. PDF 변환 지침이 용지 크기·배율 조건을 빠뜨렸다 (파일 헤더 주석)

현재 주석은 "여백 없음 / 배경 그래픽 켜기"만 안내한다. `@page { size: 1280px 720px }`를 브라우저가 무시하고 **A4 가로(≈1122×794px)** 로 인쇄하면 1280px 폭이 넘쳐 슬라이드당 2쪽이 되거나 우측이 잘린다 → **10쪽 요건 즉시 위반.**
→ 수정: 주석에 "용지 크기는 기본값(맞춤) 유지 · 배율 100% · 출력 후 **총 10쪽인지 반드시 확인**" 추가. 담당: deck-producer.

### W-6. 표지 "5인"이 미확정 사실로 단정돼 있다

표지 meta에 `[TODO: 팀명] · 5인`. 입력 문서 §9는 **역할 5개 영역**을 정의할 뿐 인원수를 명시하지 않는다. Mission은 3~5인 유동 배정이며 팀 확정 전이다(`CLAUDE.md` 백로그). 4인 배정 시 표지·10p 표가 동시에 어긋난다.
→ 수정: 팀 확정 전까지 `[TODO: 팀명] · [N]인`으로 표기하거나 인원수 삭제. 담당: deck-producer.
