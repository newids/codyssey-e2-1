### W5-1. 제출 계층 정규식이 컴포넌트 ID와 충돌한다 — 게이트 오탐 12건 【권고 / strategy-planner】

v1.6이 §⑦-9의 금지 ID 목록에 **`C\d+`(감축 ID)** 를 추가하면서, **결정론 코어 컴포넌트 ID `C1`–`C6`** 과 정면 충돌한다. 실측 결과 덱 3건·D6 3건 등 **12건이 검출**되나 전부 §⑦-10이 허용한 **정의 표 ID 열**의 정상 표기다.

**수정 요구:** 감축 ID를 `C\d+` → **`CUT-\d+`** 같이 컴포넌트와 겹치지 않는 접두로 바꾸거나, 정규식을 `(?<!\bID\b.*)C\d+` 대신 **"감축 ID는 진행 계층 전용이므로 제출 계층 검사 대상에서 제외"** 로 명문화한다. 지금 상태로는 매 라운드 오탐 12건을 사람이 손으로 걸러야 한다.

아울러 **D1-M 실행 시점을 「증분 문안 확정 직후」로 앞당길 것**(§① 참조).
