# 반려

**반려 4건 / 수정 권고 9건 / 참고 7건 / 판단 유보 1건.**

전략 v1.1의 논리 골격은 두 산출물에 충실히 이식됐고, 금지어 14종 전수 스캔에서 위반 0건, 통계 수치 13종 대조에서 값 불일치 0건이다. **논증의 질은 통과선 위에 있다.** 반려는 전부 (a) 기계적 형식 게이트, (b) 두 문서가 서로를 모른 채 작성돼 생긴 경계면 결함, (c) 검증 가능한 외부 링크와 산출물 주장 간의 괴리에서 나온다. 내용 재설계는 요구하지 않는다.

**가장 심각한 구조적 사실:** 덱은 기획서 없이 제작됐고, 그 결과 **팀 역할 분담이 두 문서에서 서로 다른 체계로 존재한다.** 이것은 Mission §7 필수 요건에 직접 걸린다.

### R-1. 기획서 A4 2쪽 초과 — 형식 게이트 위반

| 항목 | 내용 |
|---|---|
| 위치 | `03_proposal_draft.md` 전체 |
| 기준 | `Mission-e2-1.md` §2-1 "a4 인쇄 기준 2p 이내" |
| 측정 | 총 7,220자(공백 포함) / 5,467자(공백 제외) / 한글 음절 3,502자. 4쪽 분량 표(표 줄 25행) + 18행 ASCII 다이어그램 1개 |
| 추정 | A4·10pt·행간 160%·여백 2.5cm 기준 1쪽 ≈ 2,200자 → **본문만 3.3쪽**. 표는 셀 줄바꿈으로 원문자수보다 2~3배 세로 공간을 먹고, 다이어그램은 76열 고정폭이라 축소 없이는 1/3쪽을 점유한다. **실측 예상 4.0~4.5쪽** |
| 극단 압축 시 | 9pt·행간 130%로 밀어도 1쪽 ≈ 3,190자 → 2쪽 = 6,380자. 여전히 미달이며 그 타이포그래피는 심사 가독성에서 별도 감점 |

**예상 심사 질문:** *"2쪽 이내가 요건인데 이건 4쪽입니다. 요건을 못 읽으신 건가요, 아니면 못 줄이신 건가요?"* — 형식 위반은 내용을 읽기 전에 신뢰를 깎는다. 심사위원은 "이 팀은 제약 조건 하에서 우선순위를 못 정한다"로 읽는다.

**수정 요구 (약 35~40% 감축, 2,600~2,900자 삭감):**
1. **§5 시스템 구성 ASCII 다이어그램을 3~4행 축약형으로 교체.** 현재 18행 중 데이터 블록(5행)은 §4·§7과 중복 정보다. `[접점] → [결정론 코어 C1–C6] → [AI 레이어 A1–A5] → [데이터]` 4단 1행씩이면 대응 관계는 유지된다. 절감 약 700자.
2. **§4 AI 표의 "컴포넌트(입력 → 출력)" 열에서 입출력 상세 삭제.** A1의 "(클릭 지점·체류 시간·오답 유형)", A5의 "약관·통지문·경고문" 등 예시 나열은 발표 Q&A 자산이지 2쪽 지면 자산이 아니다. 절감 약 400자.
3. **§3 차별점 1의 KISA 서술 압축.** 630개사·255,460명·12.7%·디도스 20분 vs 64분을 전부 본문에 넣었다. **덱 슬라이드 03이 이 수치를 전담**하므로 기획서는 "국가는 기업 임직원 25만 명 규모로 이미 모의훈련을 집행 중이며(과기정통부·KISA, 2026 상반기), 시민 대상은 없다" 2문장으로 충분하다. 절감 약 500자.
4. **§1 배경의 산술 환산(212일·36.6억·69건) 중 1개만 남긴다.** 덱 슬라이드 01이 이미 3중으로 제시한다. 절감 약 200자.
5. **§7 향후 발전 방향 4개 불릿 → 2개.** "확산 순서 = 매트릭스 순서"와 "1단계/2단계"가 §2·§6과 겹친다. 절감 약 500자.
6. **§6 불릿 3개 중 "사회 관점"을 표에 흡수.** 절감 약 300자.

**담당:** proposal-writer

### R-2. 팀 역할 분담이 두 문서에서 다른 체계 — Mission 필수 요건 직결

| | 기획서 §8 | 덱 슬라이드 09 |
|---|---|---|
| 담당자명 | `[팀 확정 후 기입]` × 5 | YWKim / JHKim / YRHeo / SHkim / JSChoi (실명 기재) |
| 역할 1 | 기획 총괄·문제 정의 | 총괄 · 문제 타당성 · **기대 효과** |
| 역할 2 | **AI 설계** | **문제 정의** |
| 역할 3 | 데이터·시나리오 | 서비스 개요·핵심 기능 |
| 역할 4 | 서비스·UX | UX · **안전 설계** |
| 역할 5 | 사업화·발표 | **검증 · 수익 논리** |

**두 문서가 같은 팀을 설명하지 않는다.** 특히:
- 기획서에만 있는 **"AI 설계 (A1–A5 명세, 결정론 코어 경계 설계, AI 필연성 논거)"** 역할이 덱에는 **존재하지 않는다.** 이 프로젝트의 핵심 산출물을 만든 사람이 발표자료 R&R에서 사라진다.
- 덱에만 있는 **"검증·수익 논리"**, **"안전 설계"** 역할이 기획서에 없다.
- 기획서 헤더의 팀명·팀장도 `[팀 확정 후 기입]`인데 덱에는 5인 실명이 있다. 같은 제출물 세트가 팀 확정 전/후 두 상태로 공존한다.

**기준:** `Mission-e2-1.md` §7 필수 요건 — "모든 팀원이 기획 과정에 참여하고 **발표 자료에 역할 분담을 명시**해야 한다", §4-3 기획서 필수 항목 "팀 역할 분담 — 각 팀원의 담당 영역과 기여 내용".

**예상 심사 질문:** *"기획서에는 'AI 설계' 담당이 있는데 발표자료 R&R에는 없습니다. A1부터 A5까지 설계한 분은 누구입니까? 그리고 기획서에는 이름이 하나도 없는데, 이 발표자료의 다섯 분과 같은 팀 맞습니까?"*

**수정 요구:** 역할 taxonomy를 **한쪽으로 통일**한다. 덱 09의 5역할 체계가 기여 내용이 더 구체적이므로 이쪽을 정본으로 삼되, **"AI 설계"가 어느 팀원에게 귀속되는지 반드시 드러나게 재배분**할 것(현재 덱 5역할 중 AI 아키텍처를 담당한 사람이 없다 — 이것이 심사에서 "그럼 A1–A5는 누가 만들었나"를 부른다). 확정한 체계를 기획서 §8에 그대로 복사하고, 담당자명은 R-x가 아닌 [제출 전 해소 목록] 항목으로 넘긴다.

**담당:** proposal-writer(§8 교체) + deck-producer(09 역할명 조정) — **먼저 오케스트레이터가 정본 체계를 확정할 것.** 두 에이전트가 독립 수정하면 같은 불일치가 재발한다.

### R-3. 덱이 링크한 프로토타입이 덱의 주장과 정면 충돌 — 검증 가능한 반증

**충돌 4건:**
1. 덱 L313 A3 선택 이유 — *"고정 문항은 3회면 소진된다. 무한 변형이 반복 훈련의 성립 조건"*. 링크된 프로토타입은 **정확히 고정 문항 3라운드**다. 덱이 자기 논거를 자기 링크로 반증한다.
2. 덱 L311 A1 — *"LLM few-shot 분류 + 규칙 스코어링"*로 취약 자극 유형(권위·공포·이득·긴급·친밀)을 판별. 프로토타입에 **취약 자극 유형 개념 자체가 없고**, 프로필은 사용자가 직접 고른 값이다. LLM 호출 코드 0건.
3. 덱 L285–287 칩 — "음성 우선(TTS) 출력", "시각 스포트라이트". 소스 전수 검색 결과 `speechSynthesis`/`spotlight` **구현 0건**. 이 칩 바로 아래에 CTA가 놓여 있어 심사위원은 이 셋을 확인하러 클릭한다.
4. 덱 L280 — "당신의 취약 자극: **권위 순응** → 이 유형 집중 훈련 큐에 편성". 프로토타입 `Result.jsx`는 점수 N/3과 격려 문구만 출력한다. **실패 해부 화면도, 큐 편성도 없다.**

**예상 심사 질문:** *"지금 링크를 열어봤습니다. 문항이 고정이고 프로필은 제가 직접 골랐고 음성도 없습니다. 여러분이 슬라이드에서 '고정 문항은 3회면 소진된다'고 하셨는데, 그럼 이 프로토타입은 무엇을 증명하는 겁니까? AI는 어디에 있습니까?"* — 이 질문 하나로 AI 필연성 축 전체가 흔들린다. 링크가 없었다면 나오지 않았을 질문이다.

**수정 요구 (셋 중 택1, 난이도순):**
- **(a) 라벨 정정 + 범위 캡션.** CTA 문구를 "판단형 미션 프로토타입" → **"고정 문항 판별 훈련 데모(A3 생성기 미적용)"**로 바꾸고, 아래에 1행 캡션: *"현재 데모는 결정론 코어(C1·C2)와 판단형 미션 UI만 구현. A1 프로파일링·A3 생성기·A5 음성은 미구현 — 구현 범위를 정직하게 표기한다."* **이 정직 표기 자체가 현실성 축의 가점이 된다.**
- (b) CTA를 슬라이드 05(칩 3종 바로 아래)에서 분리해 별도 위치로 이동 — 암묵적 약속을 끊는다.
- (c) 링크 제거.

**(a)를 권고한다.** 작동하는 프로토타입 보유는 이 팀의 몇 안 되는 실물 증빙이며, 범위를 명시하면 자산으로 남는다. 숨기거나 과장하면 부채가 된다.

### R-4. AI Fintech "산업 현황과 주요 이슈"가 두 산출물 어디에도 없음 — 루브릭 1-① 미충족

**전수 검색 결과: `금융위`·`7대 원칙` 등장 = 기획서 0회, 덱 0회.**

| 확보 자산 (`PROJECT_BRIEF.md` §1) | 산출물 반영 |
|---|---|
| AI 기본법 2026.1 시행 | **없음** |
| 금융위 AI 활용 7대 원칙(거버넌스·합법성·보조수단성·신뢰성·금융안정성·신의성실·보안성) 통합 가이드라인 | **없음** (원칙 이름만 덱에 괄호로 산재) |
| 전자금융감독규정 시행세칙 개정 — 2026.4.20 망분리 규제 완화 | **없음** |
| 금융위 포용금융 전략 추진단(2026.5.28 구성, 4개 분과) | **없음** |
| 행안부 AI 기반 공공데이터포털 시범서비스 | **없음** |

산출물에 등장하는 통계는 전부 **경찰청(치안)·NIA(정보화)·한은/금감원(금융이해력)·KISA(정보보호)** 계열이다. `Mission-e2-1.md` §3 첫 번째 과제 목표 *"제시된 도메인의 산업 현황과 주요 이슈를 파악하고 설명할 수 있다"* 에 대해, **산출물만 읽고는 AI Fintech 산업이 지금 어떤 국면인지 답할 수 없다.**

더 나쁜 것은 덱이 원칙 이름을 **근거 없이 괄호로만 흩뿌린다**는 점이다:

| 덱 위치 | 표기 | 문제 |
|---|---|---|
| L258 | (보안성) | 출처 무표기 |
| L259 | (보조수단성) | 출처 무표기 |
| L261 | (신의성실) | 출처 무표기 |
| L287 | **(설명가능성)** | **금융위 7대 원칙 목록에 없는 명칭** (`PROJECT_BRIEF` §1 확인) |
| L298 | (거버넌스) | 출처 무표기 |
| L314 | (신뢰성) | 출처 무표기 |

다섯 개가 정확히 7대 원칙 명칭이라 심사위원은 이를 **원칙 매핑 시도**로 읽는다. 그런데 (a) 어느 기관의 무슨 원칙인지 슬라이드에 없고, (b) 여섯 번째가 목록에 없는 이름이며, (c) **합법성·금융안정성 2개는 대응이 아예 없다.** 절반만 맞춘 매핑은 매핑을 안 한 것보다 나쁘다.

추가로 — **전략 §5-1이 "기획서 AI 원칙 대응 표의 보조수단성 행이 이 설계를 근거로 채워진다"고 명시 지시했으나, 기획서에 그 표가 없다.** 전략-산출물 추적 실패.

**예상 심사 질문:** *"AI Fintech 도메인 과제인데 인용 통계가 경찰청·NIA·KISA뿐입니다. 금융 AI 규제 환경 조사는 하셨습니까? 그리고 슬라이드 괄호의 '보조수단성', '신의성실'은 어느 기관 원칙입니까? 7개 중 몇 개에 대응하셨습니까?"*

**수정 요구:**
1. **기획서 §1 배경 앞에 2~3문장 산업 현황 문단 신설** (R-1의 감축분으로 지면 확보): AI 기본법 2026.1 시행 + 금융위 AI 활용 7대 원칙 통합 가이드라인 + 망분리 규제 완화(2026.4.20)로 금융권 AI 도입 조건이 열린 국면이며, 그 안에서 **소비자 보호·사기 예방이 포용금융 전략 추진단(2026.5.28)의 정책 축**이라는 좌표를 1문단으로 제시. 출처는 `PROJECT_BRIEF` §1·§6 그대로.

### W-5. 덱이 PDF 제출 형식이 아니며, 인쇄 시 내용 잘림 버그가 있다

`Mission-e2-1.md` §2-2·§7: **"형식: PPT 또는 PDF (10P 이내)"**. 현재 산출물은 HTML이다. 작업본 단계라면 정상이나, PDF 변환에 **실제 버그**가 있다:

```css
.slide { height: 100vh; overflow: hidden; }   /* 기본 */
@media print {
  body, main { overflow: visible; height: auto; }
  .slide { height: 100vh; page-break-after: always; }  /* overflow:hidden 해제 없음 */
}
```

`@media print`에서 `main`의 overflow만 풀고 **`.slide`의 `overflow: hidden`은 그대로 남는다.** 100vh를 넘치는 슬라이드는 인쇄 시 **아래가 조용히 잘린다** — 오류 없이, 눈치채지 못한 채. 위험 슬라이드: **06(아키텍처 밴드 2개 + 6칩 + 5행 speclist + 긴 muted)**, **09(5행 표 + 3항 Lessons)**, **02(4열 표)**. 특히 09가 잘리면 **팀 R&R이 잘리는 것**이고, 이는 Mission 필수 요건 미충족으로 직결된다.

슬라이드 수는 10개(00~09)로 10P 이내 ✓.

**예상 심사 질문:** (질문이 안 나온다 — 그냥 잘린 채 채점된다. 그래서 더 위험하다.)

**수정 요구:**
1. `@media print`에 `.slide { overflow: visible; height: auto; min-height: 100vh; }` 추가.
2. **A4 가로 또는 16:9로 실제 PDF 출력 후 10쪽 전량 육안 확인** — 특히 06·09 하단. 확인 전에는 통과 처리하지 않는다.
3. 제출본은 PDF로 낸다.

**담당:** deck-producer

**덱은 미션 3분류를 한 번도 설명하지 않는다.** 그런데 마지막 슬라이드에서 팀원의 핵심 기여로 제시된다. 청중은 처음 보는 개념을 성과로 들이받는다. 슬라이드 07의 "3분 만에 내 지원금 찾기"가 생활해결형이라는 것도, 슬라이드 05 데모가 판단형이라는 것도 연결되지 않는다.

기획서는 §3에 3분류를 정의하므로 **기획서를 읽은 사람만 덱 09를 이해한다** — 전형적인 덱-선행-제작 결함.

**예상 심사 질문:** *"미션 3분류가 뭡니까? 발표에서 못 들은 것 같은데요."*

**수정 요구:** 덱 슬라이드 04 칩 줄에 1칩 추가 — `미션 3분류: 판단형(주력) · 행동형(온보딩) · 생활해결형(진입 훅)`. 1줄로 09의 기여 서술이 착지한다.

### W-9. 사람 에스컬레이션의 공급 주체·비용이 미정 — 보조수단성 논거의 취약점

기획서 §3 / 덱 L253: *"같은 유형 3회 이상 피격 시 기관 상담사·교육 담당자 연결"*. 이 설계는 전략 §5-1이 **금융위 보조수단성 원칙 대응의 핵심 논거**로 지정한 것이다. 그런데 산출물에 **그 상담사가 누구인지, 누가 인건비를 대는지, 응대 규모가 얼마인지** 전무하다.

수익 구조상 시민은 무료이고 기관이 리포트를 산다. 그렇다면 상담 인력도 기관 부담이어야 하는데, 그 전제가 어디에도 없다. B2G 제안 시 기관이 가장 먼저 묻는 항목이다.

**예상 심사 질문:** *"3회 걸리면 상담사에게 연결한다고 하셨는데, 그 상담사는 여러분이 고용합니까? 전 국민 대상이면 몇 명이 필요합니까?"*

**수정 요구:** 기획서 §3 에스컬레이션 문장에 삽입 — *"연결 대상은 도입 기관이 이미 운영 중인 상담·교육 인력이며, 우리는 트리거와 인계 리포트만 제공한다(자체 상담 인력을 고용하지 않는다)."* 전략 §3-6의 "기관 보유 기기 탑재" 원칙과 같은 논리이므로 정합적이다. 덱 L259 칩에 "(기관 인력 활용)" 3자 추가.
**담당:** strategy-planner(설계 확정) → proposal-writer + deck-producer

### N2-3. 덱 08/10 카드에 W-7 폐기 표현 잔존 — **수정 권고**

```
<div class="card"><b>기관 — 구매자</b><p>… 지금은 아무도 증명하지 못하는
<strong>"교육 효과"를 훈련 전후 수치로</strong> 제출할 수 있게 된다.</p></div>
```

§8-5는 *"두 문장 모두 아래 문안으로 치환한다. **원문을 남기지 않는다.**"* 이고, 원칙은 *"'아무도 없다'(전수 조사 주장)와 '확인되지 않았다'(우리가 조사한 범위의 진술)는 방어 난도가 전혀 다르다. **후자만 쓴다. 이 규율은 다른 모든 문장에도 적용한다.**"* 이다.

같은 슬라이드 `sub`에는 정본 문장(*"…확인되지 않았다"*)이 들어갔는데 **카드는 수정되지 않아, 한 슬라이드 안에 강도가 다른 두 진술이 공존**한다. 심사위원은 약한 쪽이 아니라 **강한 쪽(아무도)을 공격**한다.

**수정 요구:** `지금은 아무도 증명하지 못하는` → **`지금은 지표로 요구되지 않는`**. 6글자 교체.
