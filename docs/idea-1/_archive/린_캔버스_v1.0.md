## 1. 문제 (Problem)

1. **아는 것이 사기 순간에 작동하지 않는다** — 지식-행동 전이 실패. 취약계층은 접근 96.5%·활용 80.0%인데 역량만 65.6%다 (NIA, 2024).
2. **교육 시점과 사기 시점의 간격** — 1회성 수강은 시간이 지나면 감쇠한다.
3. **피해는 전 연령으로 확산** — 2025년 1–7월 누적 7,766억 원(경찰청 국수본), 기관사칭형 피해자의 52%가 30대 이하(2025).

**기존 대안:** 지식 전달형 금융교육(금감원 금융교육포털), 사후 탐지(시티즌코난), 거래 시점 차단(은행 FDS) — 모두 유효하지만 **모두에게 같은 것을 한 번 주거나, 이미 벌어진 다음에 개입한다.**

## 2. 고객군 (Customer Segments)

**사용자 ≠ 구매자.**

- **사용자:** 1군 60대 이상 / 2군 20·30대 / 3군 50대 (피해 규모 × 역량 취약도 매트릭스 순)
- **구매자(공공 도입, B2G):** 시민 대상 교육·디지털역량 사업을 집행하는 기관
- **1차 검증 집단:** 진입 가능한 공공 교육사업이 40~64세에 집중돼 있어 베타는 50~64세부터 실측한다

## 3. 고유 가치 제안 (UVP)

**카테고리:** AI 기반 전기통신금융사기(보이스피싱·스미싱) 대응역량 훈련 체계.

> **"당신이 어떤 미끼에 약한지 AI가 찾아내고, 그 미끼만 골라 예고 없이 반복해서 던진다."** (한 문장 정의 — 동결)

**하이레벨 컨셉:** 국가가 기업 임직원에게만 시행 중인 모의훈련을, 시민 개인 단위로.

## 4. 솔루션 (Solution)

1. **5단계 반복 훈련 절차** — 사전 행동수칙 교육(3분) → 취약 유형 진단 → 변형 시나리오 무예고 훈련 → 피격 지점 사후 분석 → 대응역량 재평가
2. **훈련 모듈 3분류** — 판별형(주력, 기관사칭 40% 이상) / 행동형(사전 행동수칙 교육 + 모의 이체) / 생활과제형(진입 훅)
3. **판별 결과에 실제 사례 근거를 함께 제시**(신뢰성 원칙 대응)
4. 3회 이상 반복 피격 시 **기관 상담 인력으로 전문 상담 연계**. 사용자 간 상호 교육은 채택하지 않는다

## 5. 채널 (Channels)

1. 공공 교육사업 진입 — 서울시50플러스재단 시민제안형 교육과정 · 서울시평생학습포털 (**연계 검토 대상**, 절차·요건 미확인)
2. 디지털배움터 — 65세 이상·청년 커버, 전국 확산
3. **개인 확산 — 훈련 결과 공유 카드** (서비스 경험의 전달이지 금융 판단의 전달이 아님)

## 6. 수익원 (Revenue Streams)

3층 유인 구조(개인 = 무료 실익 / 기관 = 이행 실적 + 훈련 전후 수치 / 사회 = 피해 절감).

1. 공공 도입(B2G) 훈련 프로그램 공급 (기관 보유 기기 탑재)
2. **기관 대응역량 진단 리포트** (자극 유형별 피격률, 기관·지역 단위 평균과 1회차 대비 개선폭, 최소 인원 미달 시 미산출)
3. B2B 금융회사 제휴

**금융상품 판매·중개 수익 없음.**

## 7. 비용 구조 (Cost Structure)

- LLM API (훈련 시나리오 자동 생성·해설 재작성. 판별 퀴즈는 사전 생성·캐시로 호출 0)
- 개발·운영 인건비, 서버리스 인프라
- 시나리오 데이터셋 구축·검수 (사람 라벨링)
- **상담 인력을 자체 고용하지 않는다** — 도입 기관 인력으로 연계하므로 이용자 증가가 인건비 선형 증가로 이어지지 않는다

## 8. 핵심 지표 (Key Metrics)

1. 피격률(클릭·정보입력·오판) 감소 — 1회차 대비 N회차
2. 자극 유형별 **대응역량 취약도 지수** 변화 — 재측정값 시계열
3. 반복 참여 효과 — 재참여자 vs 신규 참여자
4. 훈련 완주율 (3분 제약 충족 여부)
5. 공공 도입 기관 수 · 집단 규모

## 9. 경쟁 우위 (Unfair Advantage)

1. **국가가 검증한 방법의 미적용 영역** — 2026년 상반기 630개 기업·임직원 25만 5,460명 대상 모의훈련이 집행됐으나, 이에 대응하는 시민 대상 상시 모의훈련 프로그램은 확인되지 않는다
2. **진단 축의 신규성** — 콘텐츠가 아니라 사람을 진단하고, 개인 취약 자극 유형만 집중 노출한다
3. **원천 데이터 기반 설계** — 경찰청 연령별 피해현황(2016–2025) 원천 데이터로 세그먼트·문항 구성비를 정한다 (기관사칭형 51% → 훈련 문항 40% 이상)
