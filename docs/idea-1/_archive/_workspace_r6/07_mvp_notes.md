## 2. 학습자 화면 쉬운 말 문안 무변경 확인

소스 diff 전체가 위 5건(실변경 9줄, 그중 4줄이 테스트)뿐이다. 학습자 문안은 문자열 하나도 바뀌지 않았고 빌드 산출물에서 원문 그대로 검출된다.

| 학습자 표면 | 번들 검출 |
|---|---|
| 온보딩 3문항 · 행동수칙 브리핑 본문 4개 · 라운드 안내 · 적응형 해설 | 유지 |
| 결과 화면 `자극 유형별 취약도` 제목 · 산식 1줄 · `측정 중` | 유지 |
| 공유 카드 고지 `…금융 판단의 조언이 아닙니다.` | 유지 |
| 합성 데이터 배지 `예시 데이터(합성)` | 유지(변경 금지 대상) |

- 4번(공유 카드 머리말)은 학습자 화면 문자열이지만 **전략 v2.0이 명시적으로 교체를 지시한 항목**이며, 교체어(`금융안전 실습 결과`)도 쉬운 말이라 §⑪-6의 쉬운 말 원칙과 충돌하지 않는다.
- 모듈 번호(①②③)·우산 명칭·컴포넌트 ID는 MVP 화면에 없다(승계 확인).

## 4. 관측 사항 (judge-redteam 판정용 — 문서를 직접 고치지 않음)

1. **배포 검증 게이트의 검사 문자열 목록이 갱신돼야 한다.** 직전 라운드에서 5번째 검사어로 추가됐던 `대응역량`은 이번 치환으로 번들에서 **사라졌다**. 현 번들 기준 유효한 검사어는 `대응 수칙`·`취약도`·`측정 중`·`예시 데이터(합성)` 4종 + 신규 `금융안전` 이며, 게이트 문서가 `대응역량`을 계속 요구하면 배포 검증이 실패한다.
2. MVP 기능·산식·데이터셋은 무변경이다. 금융안전 취약도 지수 산식, 5단계 실습 절차 구현, 합성 코호트 리포트 모두 직전 상태 그대로이며, 부록 A로 강등 보존되는 설계 자산과 실물이 일치한다.
3. MVP가 구현한 범위는 **6조 3영역 중 금융안전 영역의 판별 실습 일부**다. 발행 산출물이 MVP를 부를 때 이 범위를 넘겨 서술하지 않도록 주의가 필요하다(코드에는 은퇴 표기 `판별형 훈련 모듈`이 남아 있지 않다).
