**반려 1 · 수정 권고 3 · 참고 3.**

**SSOT 교체는 성공적으로 수행됐다.** 웹 8항목이 6조 PDF와 1:1로 대조되며, 은퇴 문자열은 실질 0건, 컴포넌트 ID 0건, `deck/` 잔존 0건이다. 5라운드에 걸쳐 쌓은 검증 자산(출처 22건·경쟁 조사 15종·취약도 산식·KISA/금융위 명분)이 **폐기되지 않고 부록에서 6조 서사에 맞춰 보존**된 것이 이번 라운드의 최대 성과다.

**반려는 하나 — 웹이 링크하는 부록 `.html` 3종이 구버전이라, 심사자가 클릭하면 폐기된 정체성이 그대로 나온다.** 정본 `.md`는 전부 갱신됐으므로 재변환 1회로 종결된다.

> **에스컬레이션 (루프 방지 규칙).** R6-1은 **"정본은 갱신했는데 실제 열리는 산출물은 구버전"** 계열의 **2회차**다(1회차: Feedback-2 R2-1 배포 프로토타입 구버전). 지난 라운드들에서 부록 `.html` 재변환은 계속 "확인 조건(문서 밖)"으로 미뤄져 왔는데, **이번 라운드는 SSOT 자체가 교체돼 성격이 달라졌다** — 단순 stale이 아니라 **폐기된 정체성의 노출**이다. **권고: `.md` 정본을 고치면 `.html`을 같은 커밋에서 재생성하도록 산출 절차에 묶을 것.** 변환이 수작업으로 남아 있는 한 이 계열은 반복된다.

### 실측

| `부록_용어와_아키텍처.html` | 08-18 10:36 | 08-19 08:02 | **14건 ✗** |

**웹 §9 링크카드 3장과 푸터가 모두 이 `.html`을 가리킨다**(`href="부록_용어와_아키텍처.html"` 등, 파일 존재 확인 ✓ — 즉 링크는 열리는데 **내용이 구정체성**이다).

**예상 심사 질문:** *"본문은 금융 학습 AI 플랫폼이라는데, 부록을 여니 '전 국민 금융역량 인프라 구상 1단계 대응역량 훈련 체계'가 나옵니다. 어느 쪽이 이 팀의 기획입니까?"* — 정체성 혼선은 이번 라운드 지시의 정반대 결과다. 방어 불가.

**수정 요구:** `.md` 정본 3종을 `.html`로 재변환해 교체한 뒤, 재변환본에서 은퇴 어휘 검출 0을 확인한다. 부록 C는 이미 0건이나 SSOT 교체분(4축 교체·§10) 반영을 위해 함께 재변환한다.

### W6-1. 웹 §6 비즈니스 모델 표가 PDF 병합 셀을 잘못 분배했다 【권고(높음) / proposal-writer】

| | PDF 원문 | 웹 현행 |
|---|---|---|
| 구조 | `가격 책정 방식` 열이 **두 행에 걸친 병합 셀** — `1) API 사용량 기반 과금 / 2) 라이선스 구독(월/연 단위 구독)`이 **B2B2C·B2B2G 공통** | B2B2C 행 → `① API 사용량 기반 과금` / B2B2G 행 → `② 라이선스 구독(월/연 단위 구독)` |

**행별로 하나씩 분배하면 "B2B2C는 API 과금, B2B2G는 라이선스 구독"이라는 PDF에 없는 대응 관계가 생긴다.** 재현 원칙(내용 이탈 0)의 유일한 실질 위반이다.

**수정 요구:** 가격 열을 `rowspan="2"`로 병합하거나, 표 아래 1줄로 `가격 책정 방식 ① API 사용량 기반 과금 ② 라이선스 구독(월/연 단위 구독) — 두 수익 구조에 공통 적용`으로 분리한다.

### W6-2. 부록 A 「금융안전 영역의 심화 설계」가 U-11 상한을 넘었다 【권고 / proposal-writer】

| 절 | 분량 |
|---|---|
| §6 금융안전 심화 설계(6 + 6-1~6-4) | **2,134자** |
| 부록 A 전체 | 6,173자 |
| **비중** | **34.6%** (상한 33.3%, **약 82자 초과**) |

6조 PDF는 3대 학습 영역을 **대등하게** 두는데 한 영역만 34.6%면 위계 오독이 난다는 것이 U-11의 취지다. **전략이 대응책까지 지정해 두었다** — `5단계 절차·실습 유형 3분류를 표 1개로 압축`(§6-2 254자 + §6-3 232자 → 표 1개). 집행하면 여유 있게 하한 아래로 내려간다.

### W6-3. 웹 §2 각주가 PDF에 없는 해석을 담았다 【권고 / proposal-writer】

> `우선 순위는 서비스 진입 순서이며 중요도 서열이 아니다 — 향후 발전 방향의 1~3단계가 같은 순서를 따른다.`

뒷절(1~3단계 순서 일치)은 PDF 내부 사실의 연결이라 재현 범위지만, **앞절("중요도 서열이 아니다")은 PDF에 없는 판단**이다. 재현 원칙 1조(창작 금지)에 걸린다.

**수정 요구:** 앞절을 삭제하고 `우선 순위는 향후 발전 방향의 1~3단계와 같은 순서를 따른다.`로 축약하거나, 각주 전체를 부록으로 내린다.
