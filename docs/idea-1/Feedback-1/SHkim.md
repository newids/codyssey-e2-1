# 취약계층 특화 접근성 보완 (UI/UX 관점)
- 음성 우선 인터페이스: TTS 방식으로 디지털 기기에 익숙하지 않은 사용자에게 편의성 제공
- 시각 스포트라이트: 텍스트 설명 방식이 아닌 클릭해도 되는 것을 강조하고 터지하지 말아야 하는 것은 어둡게 처리하여 쉬운 가이드라인 제공

# 모의 피싱 (학습 강화)
- 실제 환경이 아닌 가상 환경으로 격리시켜 개인정보를 서비스에 연동되지 않도록함
- 고도화된 피싱 시나리오를 LLM으로 생성하여 발송
- 사용자가 링크클릭이나 정보 입력 시 경고화면과 함께 어떤 속임수에 걸렸는지 시각적으로 인식하도록함

# 적응형 학습 (AI 활용)
- 사용자가 검찰 사칭, 결제, 금전적 유혹 등 어떤 자극에 취약한지 모의 훈련 데이터로 프로파일링
- 해당 시나리오에 취약한 점이 확인되면 변형 시나리오를 집중 노출하고 대처할 수 있도록 반복 훈련
- 변형 시나리오를 생성하는 공격 AI에 대해 방어 AI 또한 학습될 수 있도록 하여 미리 필터링할 수 있도록 AI 끼리 스스로 학습

- 참여를 하는 시니어들에게 미션별로 제공될 수 있는 인센티브를 지급
