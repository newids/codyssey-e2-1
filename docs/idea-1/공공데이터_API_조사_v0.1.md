## 1. 보조금24 — 대한민국 공공서비스(혜택) 정보 API

미션 3 "지원금 찾기 대화"의 데이터 소스.

| 항목 | 내용 |
|---|---|
| API 명 | 행정안전부_대한민국 공공서비스(혜택) 정보 |
| URL | https://www.data.go.kr/data/15113968/openapi.do |
| 내용 | 중앙부처·지자체·공공기관·교육청의 공공서비스(혜택) 목록 + 상세 (보조금24 원천 정보) |
| 형식 | REST, JSON + XML |
| **승인** | **개발·운영 모두 자동승인** (활용신청 후 약 30분 내 사용 가능) |
| 트래픽 | 개발계정 10,000건/일 (운영계정은 활용사례 등록 시 증설 신청) |
| 비용 | 무료 |

**신청 절차** (공공데이터포털 공통):
1. data.go.kr 회원가입 (개인=일반회원)
2. 해당 API 페이지에서 [활용신청] — 활용 목적 기재
3. 자동승인 → 마이페이지에서 인증키 발급 → 약 30분 후 호출 가능
4. Swagger 명세로 파라미터 확인 후 연동

**MVP 적용 판단**: 자동승인이므로 W1에 바로 신청한다. 다만 상세 필드 구조(지원 대상 조건의 정형화 수준)는 인증키 발급 후 실데이터로 확인 필요 — 대상 조건이 자유 텍스트라면 LLM으로 조건 매칭(오히려 AI 필연성 논거가 하나 추가됨), 정형 필드라면 필터링으로 처리. **정적 스냅샷 30건 폴백은 심사장 오프라인 대비용으로 유지**한다 (MVP 스코프 §6·§7).

참고 대안: 정부24 공공서비스 Open API 안내 페이지 https://www.gov.kr/openapi

## 2. 경찰청 — 전화금융사기 피해자 연령별 현황

세그먼트별 취약 패턴 설계·근거 통계의 원천 데이터.

| 항목 | 내용 |
|---|---|
| 데이터셋 명 | 경찰청_전화금융사기 피해자 연령별 현황_20251231 |
| URL | https://www.data.go.kr/data/15091221/fileData.do |
| 내용 | 2016–2025년 연령대별(20대 이하 / 30 / 40 / 50 / 60 / 70대 이상) 피해 현황 |
| 형식 | CSV 다운로드 (로그인 불요) + 자동변환 오픈API(JSON/XML) |
| 갱신 | 연간, 최신 수정 2026-01-20 |

**MVP 적용 판단**: 서비스 런타임 데이터가 아니라 **설계·근거 데이터**다. CSV를 받아 (a) 기획서 통계의 원천 검증, (b) 사기문자 데이터셋 30문항의 유형·세그먼트 비중 설계, (c) 데모 화면의 근거 차트에 활용. PROJECT_BRIEF의 언론 보도 인용을 원천 데이터로 보강할 수 있다 — 심사 대응력 상승.

관련 데이터셋 (필요 시 병용):
- 경찰청_보이스피싱 현황_20251231 (전체 추이): https://www.data.go.kr/data/15063815/fileData.do
- 경찰청_보이스피싱 시도청별 피해금액 현황_20251231 (지역 격차 논거): https://www.data.go.kr/data/15157710/fileData.do

## 3. NIA — 디지털정보격차 실태조사 통계자료

문해 수준 진단 설계의 기초 분포.

| 항목 | 내용 |
|---|---|
| 데이터셋 명 | 한국지능정보사회진흥원_디지털정보격차실태조사 통계자료_20251231 |
| URL | https://www.data.go.kr/data/15038422/fileData.do |
| 내용 | 모바일기기 보유율, 디지털기기 이용능력, 디지털역량 지수, 이용 효능감 등 |
| 형식 | XLSX 다운로드, 연간 갱신 |
| **라이선스** | **공공저작물 제2유형: 출처표시 + 상업적 이용금지** ⚠️ |

**MVP 적용 판단**: 온보딩 진단 문항 설계 시 연령대별 역량 분포를 참조하는 **설계 참고 데이터**로만 사용 (서비스에 데이터 자체를 재배포하지 않음). ⚠️ 제2유형(비상업)이므로 향후 사업화 단계에서는 이용 범위 재확인 필요 — 공모전·연구 단계에서는 문제 없음. 출처표시 필수.
