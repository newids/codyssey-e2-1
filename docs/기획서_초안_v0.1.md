## 0. 한 문단 요약

강의를 듣는 금융교육은 실패해 왔다. 금융 코디세이는 이노베이션아카데미 코디세이의 PBL(실전 과제)·P2P(동료학습) 모델을 금융역량 교육에 이식해, "이체 완수하기", "사기 문자 골라내기", "내 지원금 찾아 신청하기" 같은 실전 미션을 수행하게 한다. AI 코치가 학습자의 문해 수준과 속도를 진단해 미션 난이도와 설명 방식을 실시간 조정하고, 디지털에 능숙한 시민이 취약계층의 동료 멘토가 된다. 킬러 기능으로 전 연령 적응형 사기방어 훈련을 내장한다 — 같은 사기 경고가 20대에게는 요점 카드로, 70대에게는 큰 글씨·단계별 안내로 전달된다.

## 1. 문제정의

### 1-1. 금융 문해력은 전 국민 과제다

- 성인 금융이해력 65.7점. 직전 조사(66.5점) 대비 **하락**했다. (한국은행·금융감독원, 2024 전국민 금융이해력 조사)
- 고령층 디지털정보화 수준 71.4%로 계층 중 최저. 그런데 취약계층의 격차를 뜯어보면 접근 96.5%, 활용 80.0%인 반면 **'역량' 부문이 65.6%로 가장 낮다**. (NIA, 2024 디지털정보격차 실태조사) — 기기 보급의 문제가 아니라 **역량 훈련의 문제**라는 뜻이다.

### 1-2. 사기 피해는 전 연령으로 번지고 있다

- 50대 이상 피해 비중: 2023년 32% → 2024년 47% → 2025년 1분기 53%. (경찰청 국가수사본부)
- 60대 이상이 단일 연령대 피해 비중 30.6%로 전 연령대 1위. (경찰청, 2025.9 국회 제출자료)
- 동시에 20·30대 피해 비율도 2020년대 초 4%대에서 2024년 말 각 10.5% / 9.1%로 상승. 기관사칭형 피해자 중 30대 이하 청년층이 52%. (2025) — **고령층만의 문제가 아니다.**
- 피해 규모: 2025년 1분기에만 3,116억 원(전년 동기 대비 2.2배), 건당 평균 5,301만 원(1.9배). 2025년 1–7월 누적 7,766억 원. (경찰청 국수본)
- 기관사칭형이 전체의 51%. 실제 기관 전화번호 80여 개를 목록화해 피해자가 어디로 걸어도 범죄조직에 연결되도록 조작하는 수준으로 수법이 고도화됐다. (2025)

### 1-3. 기존 접근이 실패하는 이유

- **획일 강의**: 학습자마다 문해 수준·속도가 다른데 같은 강의를 틀어준다. 수료증은 남고 역량은 남지 않는다.
- **일방향 경고**: "이런 문자는 사기입니다"라는 공지는 훈련이 아니다. 실전에서 판별해 본 적 없는 사람은 실전에서 당한다.
- **연령 타겟팅의 함정**: "노인 대상 예방 교육"은 20·30대 피해 급증을 놓친다. 필요한 것은 연령 타겟팅이 아니라 **적응형 UX**다.

### 1-4. 정책 환경 (왜 지금인가)

- AI 기본법 2026년 1월 시행. 금융위원회 AI 활용 7대 원칙 통합 가이드라인 마련.
- 교육부 「모두를 위한 AI 인재양성 방안(AI for All)」 발표(2025.11.10) — 전 국민 AI 역량, 수도권-지역 격차 해소가 국가 기조.
- 금융위 「포용금융 전략 추진단」 가동 — 2026.5.28 구성·운영방안 발표 후 4개 분과 순차 가동, 금융산업분과 킥오프 2026.7.7. (금융위 보도자료)
- 행안부 「AI 기반 공공데이터포털」 서비스 개시(2026.8.3) — LLM 대화형 검색·데이터 큐레이션, 약 2개월 시범운영. (행안부 보도자료)
- 전자금융감독규정 시행세칙 개정으로 2026년 4월 20일부터 보안 평가 통과 SaaS의 내부 업무망 사용 허용 — B2G·기관 협업의 기술적 장벽 완화.

## 2. 타겟 — 생애주기 세그먼트

단일 앱, 세그먼트별 미션 트랙. 연령을 나누는 것이 아니라 **생애 단계의 금융 과업**을 나눈다.

| 세그먼트 | 핵심 과업 | 대표 미션 예시 | 사기방어 취약 패턴 |
|---|---|---|---|
| 청소년 | 첫 금융 습관 | 용돈 예산 세우고 한 달 지키기 | 온라인 거래 사기, 대리입금 |
| 청년 | 자산 형성 시작 | 내가 받을 수 있는 청년 지원금 찾아 신청서 작성 | 악성앱·명의도용, 기관사칭(30대 이하 피해자 52%, 2025) |
| 중장년 | 재무 재설계 | 퇴직연금 수령 방식 비교하고 선택 근거 설명하기 | 투자 리딩방, 대출 빙자 |
| 고령층 | 디지털 금융 적응 | 모의 환경에서 계좌이체 완수하기 | 권위 순응형 기관사칭 (60대 이상 피해 비중 30.6%, 경찰청 2025.9) |

동료 멘토링은 이 세그먼트를 **가로질러** 작동한다: 디지털에 능숙한 청년·경력보유자가 고령층·취약계층의 멘토가 되는 세대 간 페어링. 청년은 가르치며 금융 지식을 다지고(가르치는 것이 가장 깊은 학습), 고령층은 사람의 속도로 배운다.

## 3. 서비스 구조

세 개의 축이 코디세이 교육 철학(자기주도 + 동료평가 + 실전 과제)을 그대로 옮긴다.

### 3-1. 실전 미션 (PBL)

강의 없음. 모든 학습 단위가 "완수해야 하는 과제"다.

- **모의 금융 환경**: 실제 뱅킹 UI를 본뜬 샌드박스에서 이체·조회·자동이체 설정을 직접 수행. 실수해도 잃는 돈이 없다.
- **사기 판별 훈련**: 실제 사례 기반 문자·통화 시나리오 중 진짜 사기를 골라내기. 오답이면 "무엇을 보고 알 수 있었는지" AI가 해설.
- **실전 연결 미션**: 보조금24 데이터로 "내가 받을 수 있는 지원금 1개 찾아 신청서 작성하기" — 학습이 곧 실익이 되는 설계.

### 3-2. AI 코치 (적응형 학습)

- 온보딩 미션과 대화에서 **문해 수준·속도를 진단**하고, 이후 모든 설명의 난이도·어휘·형식을 자동 조절.
- 같은 개념도 사람마다 다르게: 20대에게는 요점 카드, 70대에게는 큰 글씨·음성·한 번에 한 단계.
- 막히면 답을 주지 않고 **힌트를 준다** — 코디세이의 자기주도 원칙.
- 금융약관·통지문 쉬운말 번역 내장.

### 3-3. 동료 멘토링 (P2P)

- 미션 완수자가 다음 학습자의 **동료 평가자·멘토**가 되는 순환 구조.
- 세대 간 페어링: 오프라인 거점(디지털배움터·지역 캠퍼스)과 연계해 대면 멘토링 세션 운영.
- AI가 놓치는 것(정서적 신뢰, "우리 애도 이거 써요" 같은 설득)은 사람이 채운다. AI는 보조수단, 최종 관계는 사람과 사람 — 금융위 7대 원칙의 '보조수단성'과 정합.

### 3-4. 킬러 기능: 사기방어 훈련 + 실전 판별

훈련 모드와 실전 모드의 이중 구조:

- **훈련 모드**: 세그먼트별 취약 패턴(고령층: 권위 순응 / 청년층: 악성앱·명의도용)을 반영한 시나리오 훈련. 기관사칭형(전체의 51%, 2025) 최신 수법 반영.
- **실전 모드**: 의심 문자·통화 내용을 공유하면 AI가 사기 패턴을 판별하고 **연령·상황별 적응형 행동요령** 제공. 판별 근거를 함께 제시(설명가능성).

## 4. AI 아키텍처

### 4-1. 왜 AI여야 하는가 (AI 필연성)

1. **적응형 학습은 사람으로 스케일이 안 된다.** 학습자마다 문해 수준·속도가 달라 획일 강의가 실패해 온 영역이다. 1:1 튜터를 전 국민에게 붙일 수 없다면, 수준을 진단하고 설명 방식을 실시간 조정하는 것은 AI만 할 수 있다.
2. **생성형 AI로 변형되는 사기는 규칙 기반으로 못 잡는다.** 패턴이 매일 바뀌는 수법(기관번호 80여 개 목록화 수준의 고도화)에는 LLM 패턴 분석이 필수다. 규칙 기반 필터는 보조로 병행한다.
3. **쉬운말 번역은 생성 과제다.** 약관·통지문을 상대의 어휘 수준에 맞춰 다시 쓰는 일은 검색·매칭이 아니라 생성이다.

### 4-2. 구성

```
[사용자]
   │
   ▼
┌─ 진단 레이어 ──────────────────────────┐
│ 온보딩 미션 + 대화 로그 → 문해 수준·속도 프로파일 │
└──────────────┬─────────────────────┘
               ▼
┌─ 적응 레이어 (LLM) ─────────────────────┐
│ 프로파일 기반 적응형 프롬프트:               │
│ 설명 난이도·어휘·형식(카드/음성/단계별) 조절     │
│ 미션 난이도 추천                          │
└──────────────┬─────────────────────┘
               ▼
┌─ 도메인 엔진 ──────────────────────────┐
│ ① 미션 엔진: 모의 금융 샌드박스 상태 관리      │
│ ② 사기판별 엔진: LLM 패턴 분석             │
│    + 실사례 데이터셋 검색(RAG)             │
│    + 규칙 기반 필터 병행(이중 안전망)         │
│ ③ 혜택 매칭: 보조금24 API 연동            │
└──────────────┬─────────────────────┘
               ▼
┌─ 안전 레이어 ──────────────────────────┐
│ 판별 근거 제시(설명가능성) · 확신도 낮으면      │
│ "사람과 상의하세요" 유도(보조수단성) ·         │
│ 개인 금융정보 비저장 원칙(보안성)             │
└────────────────────────────────────┘
```

### 4-3. 금융위 AI 7대 원칙 대응

| 원칙 | 본 서비스의 대응 |
|---|---|
| 거버넌스 | 데이터·모델 변경 이력 관리, 사기 판별 기준 버전 관리 |
| 합법성 | 공공데이터·공개 사례만 학습 활용, 개인정보 수집 최소화 |
| **보조수단성** | AI는 힌트·판별 보조. 최종 판단은 사용자, 고위험 상황은 사람(멘토·기관) 연결 |
| **신뢰성** | 사기 판별은 LLM + 규칙 기반 이중화, 실사례 데이터셋 기반 검증, 오탐·미탐 지표 공개 |
| 금융안정성 | 모의 환경 격리 — 실제 금융 시스템에 쓰기 접근 없음 |
| 신의성실 | 판매·중개 없음. 특정 금융상품 추천하지 않는 교육 서비스 |
| **보안성** | 공유된 의심 문자 등 입력 데이터 암호화·비식별 처리, 개인 금융정보 비저장 |

### 4-4. 설명가능성 구현 방식

- 사기 판별 결과는 항상 "무엇을 보고 판단했는지"를 함께 출력한다. 예: "발신 번호가 실제 기관 번호와 다릅니다 / '앱 설치'를 요구하고 있습니다 — 기관은 앱 설치를 요구하지 않습니다."
- 훈련 모드 오답 해설과 실전 모드 판별 근거가 같은 컴포넌트를 공유 — 훈련이 곧 실전 대비가 되는 구조.

## 6. MVP 범위

### 6-1. 형태

웹앱 1종. 회원가입 없이 체험 가능한 데모 우선.

### 6-2. 미션 3종 데모

1. **이체 시뮬레이션** — 모의 뱅킹 UI에서 계좌이체 완수. 단계별 AI 힌트.
2. **사기문자 판별 퀴즈** — 실제 사례 기반 문자 3개 중 사기 골라내기. 오답 시 근거 해설.
3. **지원금 찾기 대화** — 몇 가지 질문으로 상황을 파악해 받을 수 있는 지원금 후보 제시 (보조금24 데이터 기반).

### 6-3. AI 핵심 데모: 적응형 프롬프트

- 온보딩에서 문해 수준 진단 → 설명 난이도 자동 조절.
- **비교 데모 시나리오**: 같은 사기 경고가 60대 사용자에게는 큰 글씨·단계별·음성으로, 20대 사용자에게는 요점 카드로 전달되는 화면을 나란히 시연 — "적응형 UX"를 3분 안에 증명하는 장면. (백로그 4번과 연결)

### 6-4. MVP에서 뺀 것 (의도적)

- 동료 멘토링 매칭 시스템 — 오프라인 파일럿(4050 AI Cafe)으로 대체 검증
- 실전 사기 판별 모드 — 훈련 모드 데이터셋 검증 후 2단계
- 청소년·중장년 트랙 — 고령층·청년 2개 세그먼트로 시작

### 6-5. 구현 계획 (심사 대응)

- 스택: 웹 프론트 + LLM API (적응형 프롬프트 설계 중심, 파인튜닝 불요 — MVP 비용 최소화)
- 데이터: 금감원 보이스피싱지킴이 공개 사례 기반 판별 퀴즈 데이터셋 수작업 구축(수십 건 규모로 시작)
- 검증: 4050 AI Cafe(운영 중인 AI 교육 커뮤니티, 4050aicafe.kr) 회원을 초기 베타 테스터 풀로 활용 — 중장년 실사용자 피드백을 MVP 단계에서 확보

## 7. 확산 계획

### 7-1. 단계

1. **파일럿**: 4050 AI Cafe 커뮤니티 베타 (중장년 트랙 콘텐츠 원형 보유 — 실행력 증빙)
2. **B2G 1차 — 디지털배움터**: 전국 디지털배움터의 금융역량 커리큘럼으로 공급. 강사가 동료 멘토 역할의 초기 공급자가 된다.
3. **B2G 2차 — 지역 캠퍼스**: 경산이노베이션아카데미 등 지역 기관과 연계. 코디세이 지역 확산 방향(2024.11 보도 기준 조건부 계획이나, 지역 기관은 이미 활동 중)과 동행.
4. **전국화**: 포용금융 전략 추진단(금융위, 2026.5 구성 발표, 4개 분과 가동 중) 정책 사업과의 연계 타진.

### 7-2. 왜 이 팀/이 경로인가

- "코디세이에서 배운 방식으로, 이 방식이 필요한 국민에게" — 운영 기관의 교육 철학(PBL·P2P·자기주도)을 도메인만 바꿔 이식한 것이므로, **"왜 이 방식인가"가 기관 정체성으로 이미 증명**되어 있다.
- AI for All(교육부, 2025.11.10) 기조의 금융 버전 — 정책 정합성이 서사가 아니라 구조로 맞물린다.
