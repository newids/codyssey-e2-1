\> 도메인: AI Fintech    
\> 서비스 비전: 사용자의 실제 금융 미션 수행을 기반으로 금융역량을 파악하고, AI가 기초 금융·금융안전·생활금융 중 필요한 다음 학습을 연결하는 개인 맞춤형 금융학습 플랫폼

# 1\. 문제 정의

금융교육 콘텐츠는 이미 다양하며 모바일 금융 실습, 금융사기 시뮬레이션 등 체험형 교육도 등장하고 있다. 그러나 금융생활에 필요한 역량은 여러 서비스와 콘텐츠로 분절되어 있고, 사용자는 자신의 현재 역량과 무엇을 우선 학습해야 하는지 판단하기 어렵다.

같은 연령대라도 어려움은 다르다. 어떤 사람은 모바일뱅킹 조작에 약하고, 어떤 사람은 신용·대출 개념을 이해하지 못하며, 또 다른 사람은 금융지식은 있지만 사기 상황에서 위험한 행동을 선택할 수 있다. 2024년 성인 금융이해력은 65.7점으로 직전 조사보다 하락했고, 취약계층의 디지털 접근 수준은 96.5%인 반면 역량 수준은 65.6%로 상대적으로 낮다. 보이스피싱 피해액도 2025년 1\~7월 7,766억 원에 달했다.

따라서 필요한 것은 또 하나의 금융교육 콘텐츠가 아니라 사용자가 실제 금융과업을 수행하는 과정에서 현재 역량을 파악하고 필요한 교육·실습을 개인별로 연결하는 구조다. 사람 강사가 모든 사용자의 수행과정을 지속적으로 관찰해 1:1로 가이드하기 어렵기 때문에, 이를 대규모로 개인화하기 위한 수단으로 AI를 활용한다.cu

# 2\. 타겟 사용자

금융 코디세이는 특정 연령층이 아니라 생애주기별 금융과업을 가진 전 국민을 대상으로 한다.

| 대상 | 주요 니즈 | 대표 학습 |
| ----- | ----- | ----- |
| 청소년 | 금융 기본습관 형성 | 예산관리, 온라인 거래 위험 판단 |
| 청년 | 사회생활·자산형성 시작 | 신용·대출 이해, 청년 지원제도 탐색 |
| 중장년 | 자산관리·재무 재설계 | 투자·대출 판단, 퇴직연금, 금융사기 대응 |
| 고령층 | 디지털 금융 자립 | 모바일 송금, 금융문서 이해, 기관사칭 대응 |

연령은 초기 추천의 참고정보로만 활용하고, 실제 학습경로는 **\*\*미션 수행 결과·반복 오류·AI 도움 필요 수준\*\*** 등 행동 데이터를 중심으로 개인화한다.

# 3\. 서비스 개요

금융 코디세이는 금융 미션 수행 데이터를 바탕으로 **금융역량을 진단하고, AI 가이드와 개인별 학습경로를 제공하는** 맞춤형 금융학습 플랫폼이다.

* **기초금융:** 계좌이체, 신용·대출, 금융문서 이해  
* **금융안전:** 보이스피싱·스미싱·기관사칭·투자사기 대응  
* **생활금융:** 지원제도, 연금, 금융조건 비교

기존 금융교육과 달리 개별 콘텐츠 제공에 그치지 않고, **미션 수행 결과를 금융역량 프로필로 연결해 사용자의 취약 영역에 맞는 학습을 제공한다.**

# 4\. AI 기술 적용 방안

| 핵심 기능 | 적용 기술 | 기술 설명 |
| ----- | ----- | ----- |
| 금융역량 진단 | Weighted Rule-based Scoring → ML(분류/회귀 모델)  | 사용자의 행동 데이터를 기준과 가중치에 따라 점수화하고, 이후 축적된 데이터를 학습한 ML 모델로 고도화한다. |
| AI 가이드형 실습 | Instruction LLM \+ Context Prompting \+ RAG(Embedding 기반 검색)  | LLM으로 자연어 안내·피드백을 생성하고, 프롬프트에 사용자 수준·현재 미션 단계·오류 이력·힌트 단계 등의 조건을 전달해 응답 방식을 조정한다. RAG를 통해 공식 금융자료를 답변 근거로 활용한다. |
| 개인별 학습경로 추천 | Profile-based Rule Recommendation → Learning-to-Rank  | 사용자 프로필과 사전 정의된 규칙으로 추천하고, 향후 데이터가 쌓이면 사용자별 학습효과를 반영해 추천을 정교화할 수 있다. |

# 5\. 예상 시스템 구성

사용자 앱/웹 (기초·안전·생활금융) \<-\> API 서버 (미션·규칙·학습관리) \<-\> AI 모델(LLM/RAG) & Database

사용자의 수행 데이터가 축적되면 AI가 금융역량 프로필과 공식 금융·공공정보를 활용해 가이드·피드백·다음 금융과업을 개인별로 제공한다.

# 6\. 기대 효과

### 사용자 관점

* 모든 금융교육을 처음부터 듣지 않고 현재 필요한 영역 중심으로 학습  
* AI 단계별 가이드로 초보자도 실습형 교육에 진입  
* 지식 암기보다 실제 금융과업을 반복 경험하고 점차 더 적은 도움으로 수행

### 비즈니스·기관 관점

* B2G 중심 모델: 정부·지자체·공공교육기관이 도입하고 시민은 무료 또는 기관 제공 방식으로 이용  
* 향후 플랫폼 내 반복 수행 결과, AI 힌트 수준 변화, 금융안전 위험행동 변화 등 학습 추이를 집계해 교육효과 확인  
* 금융회사·기업이 고객·지역주민에게 제공하는 B2B2C 모델로 확장 가능

# 7\. 향후 발전 방향

1. 1단계 기초 금융·금융안전·생활금융을 하나의 금융역량 프로필로 연결  
2. 2단계 취업·주거·결혼·출산·퇴직·은퇴 등 생애주기별 금융과업 확대  
3. 3단계 디지털배움터·평생교육기관·지역 교육거점 등 공공 인프라 연계  
4. 4단계 금융기관·기업의 금융소비자보호·ESG 프로그램 연계  
5. 5단계 개인이 자신의 금융역량과 다음 학습과업을 지속적으로 관리하는 **전 국민 금융역량 인프라**로 확장

# 8\. 팀 역할 분담

팀 역할은 향후 개발 직무가 아니라 이번 기획서를 작성하는 과정에서 각 팀원이 담당한 조사·설계·정리 영역과 기여 내용을 기준으로 작성한다.

| 담당 영역 | 기획서 작성 과정에서의 기여 내용 |
| ----- | ----- |
| 기획 총괄 | 아이디어 방향 설정, 문제 정의, 서비스 핵심 콘셉트 및 전체 기획서 구성·통합 |
| 시장·사례 조사 | 기존 금융교육·AI 금융서비스 및 유사 서비스 조사, 기존 서비스 대비 차별점 도출 |
| AI 기술 조사 | LLM, RAG, 행동 데이터 분석, 개인화 추천 등 적용 가능한 AI 기술 조사 및 적용 방안 구체화 |
| 금융·데이터 조사 | 금융이해력, 디지털 역량, 금융사기 피해 등 관련 통계·정책·공공데이터 조사 |
| 서비스 설계·발표 | 타겟 사용자, 학습 흐름, 시스템 구성, 기대 효과·사업화 방향 정리 및 발표자료 구성 |

\> 핵심 제안: 금융 코디세이는 새로운 금융교육 콘텐츠를 하나 더 만드는 서비스가 아니다. 사용자의 실제 금융 미션 수행을 통해 ‘지금 무엇을 어려워하는지’를 파악하고, AI가 필요한 도움과 다음 금융과업을 연결함으로써 흩어진 금융교육을 개인별 하나의 학습 여정으로 만드는 플랫폼이다.
